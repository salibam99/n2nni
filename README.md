# n2nni — Noise2Noise denoising for neutron imaging

We are training a Noise2Noise model to denoise neutron radiographs taken at CROCUS (~100 µm pixels, 2048×2048 FITS frames). Noise2Noise needs no clean images: it learns from pairs of independent noisy measurements of the same scene. Because each object, open beam (OB) and dark current (DC) is acquired as a stack of repeated static shots, `n2n_data` builds these pairs on the fly: an input is the sum of k raw frames, the target is the sum of k *other* frames of the same stack, so the noise in input and target stays independent. The model is trained on raw counts (no filtering, no DC subtraction); objects and OB are then denoised separately and flat-field normalized afterwards, `(obj − DC) / (OB − DC)`. Raw data stays in `data_ni_crocus/` (never committed); `python -m n2n_data.build` scans it into `catalog/manifest.json` (de-duplicated frames, OB/DC links, a fixed 20 % validation split by acquisition), and `n2n_data.N2NPairs` reads crops straight from the original files, so nothing is copied to disk.
